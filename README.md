# ГродноАвтоПомощь: счета и акты в Telegram

**Демонстрация:** https://claude.ai/artifact/JghLnQ5QxbCAEkQYX7p8Ng

На странице по шагам показано, как это работает:

1. Пришла заявка на эвакуацию.
2. Диспетчер открывает форму в Telegram-боте.
3. Заполняет пять полей: заказчик, машина, откуда, куда, сумма.
4. Бот присылает готовый PDF счёта.
5. Счёт пересылается клиенту в Viber или Telegram.
6. Счёт сам появляется в общей Google Таблице.
7. После поездки акт делается одной кнопкой.
8. Когда клиент оплатил, статус меняется в таблице, и список должников пересчитывается сам.
9. Новый заказчик добавляется по УНП: название и адрес подставляются из реестра налоговой.

Сценарий проигрывается сам. Его можно поставить на паузу и листать по шагам.
